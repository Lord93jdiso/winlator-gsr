# Winlator GSR Edition (based on Winlator 11.2)

Форк **Winlator 11.2** (исходники тега `v11.2.0`) с интеграцией **Qualcomm Snapdragon GSR (SGSR1)**,
генерацией кадров, кастомными драйверами, кастомными скинами кнопок и золотой темой.
Оптимизирован под **Snapdragon 680 (Adreno 610)**.

## Что добавлено

### 1. Snapdragon GSR (Qualcomm SGSR1) — реальный апскейл
- Шейдер из официального репозитория Qualcomm (`SnapdragonGameStudios/snapdragon-gsr`,
  BSD-3-Clause) интегрирован в GLES-композитор Winlator (`EffectComposer`).
- Игра рендерится в пониженном разрешении (масштаб 50–100%), итоговый кадр
  растягивается 12-tap Lanczos-подобным фильтром SGSR1 с адаптивной резкостью —
  картинка почти как нативная, FPS заметно выше.
- Включение/выключение **прямо внутри контейнера**:
  - кнопка **GSR** в боковом меню (выезжает по Back или тапу 4-мя пальцами),
  - плавающие кнопки **GSR / FG** на экране (скрываются из меню),
  - настройка в параметрах контейнера (вкл + масштаб рендера).

### 2. Генерация кадров (dup+blend, как в GameHub-приложениях)
- Композитор рисует в ритме vsync и вставляет интерполированные (blend) кадры
  между кадрами игры: 30 fps → плавные ~60 fps.
- Переключается из бокового меню, плавающей кнопкой **FG** и в настройках контейнера.
- Требования минимальные — работает даже на Adreno 610.

### 3. Драйверы Snapdragon: встроенные + кастомные
- Новый менеджер в **Настройки → Snapdragon Graphics Driver (Turnip)**:
  выбор версии, импорт и удаление драйверов.
- Импорт кастомных драйверов: **.zip, .tzst, .tar.zst, .xz** с `libvulkan_*.so`
  (+ опционально ICD-манифест). Архив без манифеста автоматически упаковывается
  в turnip-компонент с корректным ICD json.
- Переключение встроенных и кастомных версий — в настройках драйвера Turnip
  у контейнера; применяется при запуске контейнера.
- Vortek-драйвер по-прежнему поддерживает adrenotools-драйверы (.zip с json-манифестом).

### 4. Кастомные картинки кнопок
- Редактор контролов → настройки элемента → **Custom button image** → Choose image.
- Картинка из галереи масштабируется, кладётся в профиль и рисуется вместо текста/иконки.
- Хранится в профиле (`controls_profiles/custom_images/<id>/`), переживает перезапуски.

### 5. Профиль Snapdragon 680 (одна кнопка)
- В настройках контейнера: **⚡ Apply Snapdragon 680 Profile**:
  - экран 1280x720, GSR включен (масштаб 60%), FrameGen включен,
  - Box64 preset = Performance (BIGBLOCK=3 и т.д.),
  - Turnip (нативный Vulkan-драйвер Adreno) + DXVK с `dxgi.maxFrameLatency=1`.

### 6. Золотая тема (вместо синей)
- Полная перекраска: тёмно-золотые фоны, золотые акценты, кнопки, спиннеры,
  переключатели, лого, шапка меню — всё переведено на золотую палитру.

## Сборка (локально)
```bash
# JDK 17, Android SDK (platform 34, build-tools 34.0.0, NDK 24.0.8215888, CMake 3.22.1)
./gradlew :app:assembleDebug
```

## Сборка в облаке (GitHub Actions)
1. Создай репозиторий на GitHub и залей содержимое этой папки.
2. Actions включены по умолчанию; workflow `.github/workflows/android-build.yml`
   соберёт APK и выложит его в артефакты (`Winlator-GSR-*-arm64.apk`).
3. Пуш тега `v1.0` тоже запускает сборку.
